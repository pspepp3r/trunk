# Trunk Docs

The documentation site for Trunk, built with [VitePress](https://vitepress.dev).

## Running locally

```bash
npm install
npm run docs:dev       # http://localhost:5173
npm run docs:build     # static output in .vitepress/dist
npm run docs:preview   # serve the built output
```

## Contributing

Found something unclear, outdated, or missing? Pages live under [`tutorial/`](tutorial/introduction.md) and [`guide/`](guide/routing.md) as plain Markdown - open a PR. Small fixes (typos, broken links, a missing option) are welcome without prior discussion; anything that reorganizes a page or adds a new one is easier to land if you open an issue first.
